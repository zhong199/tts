# White-Hat Promotion Plan

This file contains safe promotion tasks for `https://ttsvoice.top`.

## GitHub

- Keep the README updated with live links and use cases.
- Use repository topics such as `text-to-speech`, `tts`, `ai-voice`, `voice-generator`, `ssml`, `flask`, `huggingface-spaces`, `accessibility`, `elearning`, `youtube-tools`.
- Pin the repository on the GitHub profile if possible.
- Share meaningful updates in releases when new features are added.

## Product and Tool Directories

Submit manually where the tool is relevant and allowed:

- AlternativeTo
- SaaSHub
- Futurepedia
- There's An AI For That
- Product Hunt
- Hacker News "Show HN" only when the site is stable and the post is genuine
- Reddit only in relevant communities and only when it answers a real request

## Content Ideas

- "How to create YouTube voiceovers without recording your voice"
- "Free Japanese text to speech for language learners"
- "Using SSML to make AI voiceovers sound more natural"
- "Batch text to speech for e-learning course creators"
- "Prototype app narration before integrating a paid TTS API"

## Rules

- Do not buy links.
- Do not post the same message repeatedly.
- Do not use automated comments, issues, pull requests, or forum posts.
- Do not promise commercial rights beyond the relevant third-party TTS terms.
- Keep every post useful on its own, even if the reader does not click the link.
