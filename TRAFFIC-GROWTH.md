# Traffic Growth System

Goal: grow `https://ttsvoice.top` toward 3,000 legitimate daily visits through useful content, search discovery, open-source visibility, and safe distribution.

This plan does not use fake traffic, fake backlinks, automated comments, purchased links, or platform spam.

## Current Growth Assets

- Website: https://ttsvoice.top
- Use-case hub: https://ttsvoice.top/use-cases
- Sitemap: https://ttsvoice.top/sitemap.xml
- AI crawler guide: https://ttsvoice.top/llms.txt
- GitHub repository: https://github.com/zhong199/tts
- Submission kit: `SUBMISSION-KIT.md`
- Promotion checklist: `PROMOTION.md`

## Automated Tasks

- Daily growth health check through GitHub Actions.
- Weekly white-hat IndexNow submission through GitHub Actions.
- Daily Codex growth monitor.
- Weekly Codex content expansion task.
- Monthly Codex content opportunity research.

## Path to 3,000 Daily Visits

1. Build long-tail pages around specific tasks:
   - YouTube voiceover
   - podcast intros
   - e-learning narration
   - Japanese text to speech
   - SSML examples
   - accessibility audio
   - developer TTS prototypes

2. Make every page useful enough to stand alone:
   - specific workflow
   - examples
   - internal links to the tool
   - no keyword stuffing
   - clear privacy and contact pages

3. Keep discovery files healthy:
   - sitemap.xml
   - robots.txt
   - llms.txt
   - ads.txt
   - IndexNow key file

4. Distribute in allowed places only:
   - GitHub
   - relevant AI tool directories
   - open-source showcases
   - creator communities when answering a real request
   - education and accessibility resource lists

## Measurement

Real daily visits require access to one of:

- Google Search Console
- Google Analytics
- Cloudflare Web Analytics
- server logs
- another analytics provider

If no analytics credential is available, automation must not invent traffic numbers. It should report only public technical status and next actions.

## Weekly Optimization Checklist

- Add or improve one helpful long-tail content page.
- Verify all canonical URLs return 200.
- Confirm tool pages that duplicate homepage content remain `noindex, follow`.
- Submit changed URLs through IndexNow.
- Check GitHub README and workflow badges.
- Review one community or directory where the site can be shared manually and legitimately.
